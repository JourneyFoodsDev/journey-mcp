# Contributing

Thank you for your interest in Journey AI.

- Open an issue to discuss a bug or an idea before you send a large pull request.
- `npm install && npm test`: tests run against mock data only and need no keys or network.
- Run `npm run typecheck` before you open a pull request.
- Keep tools read-only. Give every tool a clear title, a description and `readOnlyHint`.
- Never commit keys, `.env` files or real customer data.
- Security issues: see [SECURITY.md](SECURITY.md).
